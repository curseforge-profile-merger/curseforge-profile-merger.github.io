# CurseForge Profile Merger

Небольшой статический веб-сервис для объединения двух экспортированных Minecraft-профилей CurseForge.

## Что делает

- принимает два `.zip`, экспортированных через CurseForge;
- читает `manifest.json` прямо в браузере;
- объединяет `manifest.files` по `projectID`;
- при одинаковом `projectID`, но разных `fileID`, оставляет версию базового профиля;
- проверяет версию Minecraft и семейство modloader (NeoForge/Forge/Fabric/Quilt);
- по умолчанию сохраняет только `overrides` базового профиля;
- опционально добавляет из второго профиля только отсутствующие файлы `overrides`, ничего не перезаписывая;
- генерирует новый ZIP с `manifest.json` и `overrides/` в корне;
- позволяет отдельно скачать `merge-report.json` с отчётом; сам импортируемый ZIP оставляет чистым.

Все операции с ZIP выполняются локально в браузере. Файлы не загружаются на сервер.

## Запуск

Можно просто открыть `index.html`. Для браузеров, которые ограничивают локальные CDN-скрипты, удобнее запустить простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

и открыть `http://localhost:8080`.

## GitHub Pages

В репозитории уже есть `.github/workflows/pages.yml`. После push в `main` workflow собирает статический сайт и публикует его через GitHub Pages. В настройках репозитория Pages должен использовать источник **GitHub Actions**.

## Алгоритм конфликтов

Если один и тот же `projectID` присутствует в обоих manifest:

- одинаковый `fileID` → одна запись;
- разные `fileID` → остаётся версия выбранного базового профиля.

Это важно: CurseForge не принимает manifest, где один `projectID` встречается несколько раз.

## Ограничения

Сервис не обращается к CurseForge API, поэтому не проверяет, действительно ли конкретный `fileID` совместим с выбранной версией Minecraft/modloader. Он только сравнивает метаданные двух профилей. Если версии Minecraft или семейства modloader отличаются, merge по умолчанию блокируется.

`overrides/mods/*.jar` могут содержать сторонние моды. Импорт вручную распространяемого профиля может вызвать предупреждение CurseForge о файлах, не размещённых на CurseForge. Не импортируйте ZIP из недоверенного источника.
